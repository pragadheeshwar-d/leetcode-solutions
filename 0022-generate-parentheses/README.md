# 22. Generate Parentheses

## Problem
Given $n$ pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

## Approach
The submitted solution utilizes a **backtracking / depth-first search (DFS) traversal** on a state space tree (named `preOrder`). 

The search tracks the current state of construction using:
- `lp`: The count of left parentheses `(` added to the sequence.
- `rp`: The count of right parentheses `)` added to the sequence.
- `level`: The net nesting depth, representing the current excess of left parentheses over right parentheses (`lp - rp`).
- `fromRoot`: The current state of the generated parenthesis string, passed as an rvalue reference `string&&` to enable move operations.

The tree of combinations is generated by deciding at each step whether to append a left parenthesis `(` or a right parenthesis `)`.

---

## How the Solution Works
1. **Initialization**: 
   The main function `generateParenthesis` initializes the process. It reserves memory in the `ans` vector using `ans.reserve(n<<1)` (which reserves capacity for $2n$ elements). It then initiates the recursion by calling:
   ```cpp
   preOrder(1, 0, 1, "(", n);
   ```
   This represents a state where $1$ left parenthesis, $0$ right parentheses, and a net `level` of $1$ have been placed, starting with the string `"("`.

2. **Base Case**: 
   Inside `preOrder`, if `lp == n`, `rp == n`, and `level == 0`, a valid combination of length $2n$ is reached. The current string `fromRoot` is moved/pushed into the `ans` vector.

3. **Branching (Adding a Left Parenthesis)**:
   If `lp < n`, the algorithm can always safely append a `(` because we have not yet placed all $n$ left parentheses. It recurses by incrementing `lp` and `level`:
   ```cpp
   preOrder(lp+1, rp,  level+1 ,fromRoot+"(", n);
   ```

4. **Branching (Adding a Right Parenthesis)**:
   If `rp < n` and `level >= 1` (meaning there is at least one unmatched left parenthesis), the algorithm can append a `)`. It recurses by incrementing `rp` and decrementing `level`:
   ```cpp
   preOrder(lp, rp+1,  level-1 ,fromRoot+")", n);
   ```

---

## Algorithm
1. **Start** inside `generateParenthesis(n)` by reserving capacity in the member vector `ans` and calling `preOrder` with `lp = 1`, `rp = 0`, `level = 1`, `fromRoot = "("`, and `n`.
2. **Evaluate Base Case**: Inside `preOrder`, if `lp == n && rp == n && level == 0`, push the completed string `fromRoot` into `ans` and terminate the current recursion path.
3. **Explore Left Path**: If `lp < n`, recursively call `preOrder` with parameters:
   - `lp` incremented by $1$
   - `rp` unchanged
   - `level` incremented by $1$
   - `fromRoot` appended with `"("`
4. **Explore Right Path**: If `rp < n` and `level >= 1`, recursively call `preOrder` with parameters:
   - `lp` unchanged
   - `rp` incremented by $1$
   - `level` decremented by $1$
   - `fromRoot` appended with `")"`

---

## Why This Works
The correctness of this algorithm relies on maintaining two invariants of well-formed parentheses:
1. **Count Constraint**: The total number of left parentheses `lp` and right parentheses `rp` must each be exactly `n` at the end of the generation.
2. **Prefix Constraint**: In any valid prefix of a parenthesis string, the number of closed parentheses must not exceed the number of open parentheses. The variable `level` tracks this balance dynamically. By enforcing `level >= 1` before appending a closed parenthesis `)`, the algorithm guarantees that `rp` never exceeds `lp` at any intermediate step. Thus, only syntactically valid combinations are explored and eventually pushed to `ans`.

---

## Complexity

### Time Complexity
`O(4ⁿ / (n * √n))` — The total number of valid parenthesis combinations for a given $n$ is defined by the $n$-th Catalan number:
$$C_n = \frac{1}{n+1} \binom{2n}{n} \approx \frac{4^n}{n\sqrt{\pi n}}$$
At each step of the recursion, we branch at most twice. Since the recursive tree only explores paths that lead to valid configurations (due to the `lp < n` and `level >= 1` bounds), the total number of leaves in the recursion tree is exactly $C_n$. 
Because each path from the root to a leaf has a depth of $2n$ and performs string concatenations of size up to $2n$, the total time complexity is bounded by:
$$\mathcal{O}\left( \frac{4^n}{\sqrt{n}} \right)$$

### Space Complexity
`O(n²)` — The maximum depth of the recursive call stack is $2n$ (the length of the generated strings). At each frame in the call stack, a temporary string of length up to $2n$ is stored via the parameter `fromRoot`. This results in a maximum active stack auxiliary memory of $\mathcal{O}(n^2)$. 

*(Note: This excludes the space needed to store the output vector `ans`, which takes $\mathcal{O}(C_n \cdot n)$ space).*

---

## Edge Cases
- **`n = 1`**: The algorithm initiates `preOrder(1, 0, 1, "(", 1)`. The condition `lp < n` ($1 < 1$) is false. The condition `rp < n && level >= 1` ($0 < 1 \text{ and } 1 \ge 1$) is true, triggering a transition to `preOrder(1, 1, 0, "()", 1)`. At this level, the base case triggers, inserting `"( )"` into `ans`.
- **Upper Constraint `n = 8`**: At $n = 8$, the $8$-th Catalan number is $C_8 = 1430$. The recursion stack depth reaches at most $16$, easily executing within CPU and stack limits.

---

## Solution

```cpp
class Solution {
public:
    vector<string> ans;
    void preOrder(int lp, int rp, int level, string&& fromRoot, int n){
        if (lp==n && rp==n && level==0) 
            ans.push_back(fromRoot);
        if (lp<n) 
            preOrder(lp+1, rp,  level+1 ,fromRoot+"(", n);
        if (rp<n && level>=1) 
            preOrder(lp, rp+1,  level-1 ,fromRoot+")", n);     
    }
    vector<string> generateParenthesis(int n) {
        ans.reserve(n<<1);
        preOrder(1, 0, 1, "(", n);
        return ans;
    }
};
```
