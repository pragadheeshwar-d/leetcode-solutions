# 2913. Subarrays Distinct Element Sum of Squares I

## Approach
The algorithm uses a nested loop to generate every possible subarray of the array `nums` starting at index `i` and ending at index `j`. An `unordered_set` is initialized at the start of each outer loop iteration to keep track of distinct elements seen so far in the current subarray `nums[i...j]`. As the inner loop expands the subarray by moving `j` from `i` to `n - 1`, the current element `nums[j]` is inserted into the set. The size of the set represents the count of distinct elements $d$ in the subarray. The square of this count ($d^2$) is added to the running sum `res`.

## How It Works
1. Initialize `n` as the size of `nums` and `res` as `0` to store the total sum.
2. Iterate through `i` from `0` to `n - 1`, treating `i` as the starting index of subarrays.
3. In each outer iteration, instantiate an `unordered_set<int> s` to store distinct elements in the current range.
4. Iterate `j` from `i` to `n - 1`, extending the subarray to end at `j`.
5. Insert `nums[j]` into `s` using `s.insert(nums[j])`.
6. Retrieve the number of distinct elements $d = s.size()$.
7. Add $d 	imes d$ to `res`.
8. Return `res` after processing all subarrays.

## Complexity
- **Time Complexity:** `O(n²)` — There are $n(n+1)/2$ total subarrays generated by the two nested loops. Inserting an element into an `unordered_set` and querying its size takes $O(1)$ average time per subarray extension. Thus, the overall average time complexity is $O(n^2)$.
- **Space Complexity:** `O(n)` — The `unordered_set` stores at most $n$ distinct elements during the longest subarray traversal from index $0$ to $n-1$, requiring $O(n)$ auxiliary space.

## Edge Cases
- Single-element array (n = 1): The loops run once, set size is 1, and the returned sum is 1.
- Array with all duplicate elements (e.g., [1, 1, 1]): The set size remains 1 for every subarray, accumulating 1 for each subarray.
- Array with all unique elements (e.g., [1, 2, 3]): The set size grows incrementally with the subarray length.

## Solution
```cpp
class Solution {
public:
    int sumCounts(vector<int>& nums) {
        int n = nums.size();
        int res = 0;
        for (int i = 0; i < n; ++i) {
            unordered_set<int> s;
            for (int j = i; j < n; ++j) {
                s.insert(nums[j]);
                int d = s.size();
                res += d * d;
            }
        }
        return res;
    }
};
```
